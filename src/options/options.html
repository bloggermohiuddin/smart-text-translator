General

Master switch. When off, nothing is translated and the context menu is hidden.

Show the floating popup when you select text on a webpage. The right-click menu and keyboard shortcut keep working either way.

Add “Translate selected text” to the browser context menu as a fallback.

Translation

Translation mode

The language selected text is translated into.

“Auto detect” lets Google detect the language of the selected text.

Longer selections are rejected with “Selected text is too long.” (1–5000)

Prevents accidental triggers from tiny selections (characters).

Appearance

Applies to the floating translation popup on webpages.

Where the floating popup appears relative to the selection. “Auto” picks the side with more space.

Seconds before a successful translation popup closes itself. 0 = stay open.

History

Store original text, translation, languages and timestamp locally. Nothing is stored while disabled.

Browse history

Search, copy or delete past translations.

Advanced

Display a small preview of the selected text above the translation.

Show which language Google detected as the source.

Show a copy-to-clipboard button in the popup.

Read the translation aloud using the browser’s speech synthesis.

Don’t close the popup when clicking elsewhere on the page. Can also be toggled per-popup with the pin icon.

Keyboard shortcut

Default is Alt + Shift + T. Change it under “Keyboard shortcuts” on your browser’s extensions page.

Reset

Restore every setting to its default. Translation history is kept.
